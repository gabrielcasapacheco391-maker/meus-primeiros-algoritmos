# Calculadora de IMC, TMB e Gasto Calórico Diário

Este é um programa desenvolvido em **C++** que calcula o Índice de Massa Corporal (IMC), a Taxa Metabólica Basal (TMB) e estima o gasto calórico diário de um usuário com base no seu nível de atividade física. O sistema também permite comparar os dados atuais com um histórico de peso anterior.

## ✨ Funcionalidades
- Cálculo de IMC com classificação automatizada (Abaixo do peso, Normal, Sobrepeso, Obesidade).
- Cálculo de TMB utilizando as fórmulas diferenciadas por sexo biológico.
- Estimativa de calorias diárias para **Manutenção**, **Cutting** (perda de peso) e **Bulking** (ganho de massa).
- Comparação histórica de peso e evolução do IMC.

## 🛠️ Tecnologias Utilizadas
- C++
- Bibliotecas padrão: `<iostream>`, `<cmath>`, `<iomanip>`

## 🚀 Como Rodar o Projeto
1. Copie o código do arquivo `main.cpp`.
2. Cole em um compilador C++ de sua preferência (como Code::Blocks, VS Code ou um compilador online).
3. Execute o programa e siga as instruções exibidas no terminal.
